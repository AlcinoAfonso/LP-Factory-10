# Pipeline

## 1. Roteamento

- Debate → Definidos aprovados + Escopo negativo → `$lp-factory-executar-plano` → V2 → execução
- O Executor conduz e executa na sessão principal, das decisões autorizadas à conclusão, sem Plano Base, V1 nova ou camada intermediária equivalente

A supervisão operacional é Autônoma.

## 2. Limite

O Pipeline apenas roteia. As demais regras pertencem aos contratos competentes. O path deste arquivo e os nomes técnicos existentes das skills são preservados por compatibilidade; não exigem um Plano Base.
